Админ-панель Qolay — это единый личный кабинет по адресу [merchant.qolay.kz](https://merchant.qolay.kz), в котором собраны все инструменты для управления вашим заведением. Здесь вы настраиваете меню, ведёте учёт склада, управляете персоналом, анализируете продажи и контролируете загрузку залов — без лишних программ и переключений между системами.

## Что такое Qolay Админ-панель

Личный кабинет предназначен для владельцев заведений, управляющих и менеджеров, которым необходимо оперативно реагировать на изменения в работе ресторана или кафе. Все данные обновляются в режиме реального времени: изменения в меню мгновенно отражаются в приложении для гостей, а новые заказы сразу появляются в разделе аналитики.

Для сетевых заведений доступно глобальное управление — можно копировать меню между точками, объединять аналитику и управлять персоналом нескольких филиалов из единого аккаунта.

## Кто работает в админ-панели

| Роль | Основные задачи |
|---|---|
| **Владелец** | Просмотр аналитики, управление тарифами, настройка прав доступа |
| **Управляющий** | Меню, склад, персонал, залы, банкеты, отчёты |
| **Менеджер зала** | Бронирование столиков, банкеты, статус столов |
| **Шеф-повар / технолог** | Техкарты блюд, управление меню, склад |
| **Кладовщик** | Поставки, списания, инвентаризация |

## Как войти в личный кабинет

1. Откройте браузер и перейдите на [merchant.qolay.kz](https://merchant.qolay.kz).
2. Введите номер телефона или электронную почту, которые использовались при регистрации.
3. Подтвердите вход с помощью кода из SMS или введите пароль.
4. Если у вас несколько заведений, выберите нужное из списка на главном экране.

<Note>
  Для каждого сотрудника рекомендуется создавать отдельную учётную запись с нужным уровнем доступа. Это позволяет отслеживать действия персонала и ограничивать доступ к чувствительным данным, например к финансовой аналитике.
</Note>

## Требования для работы

Админ-панель работает в любом современном браузере (Chrome, Safari, Firefox, Edge) на компьютере, планшете или смартфоне. Специальная установка не требуется. Для стабильной работы необходимо подключение к интернету.
